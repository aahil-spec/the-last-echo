# the-last-echo

What We Built

floor one start with basic thirty second time loop tutorial where player run to exit door before timer reset floor two bring button and door syncing where you press button to open timed door and rush through floor three introduce echo recorder system so you record clone pressing button while you cross gap floor four feature moving platform over danger pit and teleport console to go up floor five got crazy sweeping laser hallway and hold to disable lever where you record echo holding lever to stop lasers while you safely run to final door

Controls

Move: W, A, S, D

Jump: Spacebar

Run: Shift

Dash: Q

Interact / Hold Lever: E

toggle Camera View: T

R to ECHO!

How to Play

Open the project in Godot Engine (v4.6+ recommended).

Open res://scenes/main_menu.tscn or floor_1.tscn.

Hit  play and survive the time loops!

Or Open this link :https://aahil1.itch.io/the-last-echo and download the zip file
